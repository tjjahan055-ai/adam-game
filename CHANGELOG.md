# Changelog

## 0.1.0 (unreleased): greybox, routing mechanic
- Godot 4.5.1 project, portrait, Compatibility renderer.
- Routing puzzle rules, solver, board view with tap / turn / hold-to-remove.
- Levels r01 to r03; map screen; stars; hint; local save with backup.
- Headless tests and a screenshot play-through; CI builds for Android and web.

## Known issues
- Greybox look only; final art follows the Design Officer's style frames.
- Mechanics 1 (look and inspect) and 3 (program the drone) are not built yet.
- No sound, settings or accessibility options yet.
- The result panel can cover the bottom row of a tall board.
- Android APK has not yet been tried on a real phone.
